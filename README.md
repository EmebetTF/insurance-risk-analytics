# Insurance Risk Analytics & Predictive Modeling
This project analyzes historical car insurance data from South Africa to identify low-risk customer segments, optimize pricing strategies, and build predictive risk models.

## Objectives

- Perform exploratory data analysis (EDA)
- Analyze insurance risk factors
- Conduct statistical hypothesis testing
- Build predictive models for claim severity and claim probability
- Develop explainable risk-based pricing insights
